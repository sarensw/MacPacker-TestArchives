# Password-protected test fixtures

Generated by `make_fixtures.sh` (run it from this folder) and committed so the
test suite needs no external tooling. MacPacker consumes them through
`.copy("TestArchives/password")` in `Modules/Package.swift`; the tests reach them
with `Bundle.module.url(forResource: "password")`.

Requires `7zz` (`brew install sevenzip`) and `/usr/bin/zip`.

The payload is the same everywhere:

| path                | contents            |
| ------------------- | ------------------- |
| `hello.txt`         | `encrypted hello\n` |
| `folder/nested.txt` | `nested secret\n`   |
| `public.txt`        | `public data\n`     |

| file                     | encryption                | password                             |
| ------------------------ | ------------------------- | ------------------------------------ |
| `zip_zipcrypto.zip`      | ZipCrypto (legacy PKWARE) | `password`                           |
| `zip_aes256.zip`         | WinZip AES-256            | `password`                           |
| `zip_aes128.zip`         | WinZip AES-128            | `password`                           |
| `zip_mixed.zip`          | AES-256, `public.txt` not encrypted | `password`                 |
| `zip_unicode_pw.zip`     | ZipCrypto                 | `pässwörd`                           |
| `zip_symbol_pw.zip`      | WinZip AES-256            | `p@ss w'ord"$x`                      |
| `zip_long_pw.zip`        | ZipCrypto                 | 200 × `a`                            |
| `zip_nested_outer.zip`   | none — holds `inner_encrypted.zip` (= `zip_aes256.zip`) | `password` for the inner |
| `7z_aes256.7z`           | AES-256, plain header     | `password`                           |
| `7z_header_encrypted.7z` | AES-256, `-mhe=on`        | `password`                           |
| `7z_symbol_pw.7z`        | AES-256, plain header     | `p@ss w'ord"$x`                      |

`7z_header_encrypted.7z` is the only fixture whose *listing* needs the
password — everything else lists fine and only fails on extraction.

## Missing: RAR

Encrypted RAR is a real gap, not just a missing fixture. RAR5 derives its key
with PBKDF2-HMAC-SHA256 and RAR3/4 with SHA-1, and both go through 7-Zip crypto
code that was broken until v0.18.2 (see `make_rar_fixtures.sh`). Nothing on macOS
can *create* encrypted RAR — `rar` is not redistributable and the Homebrew build
cannot be driven non-interactively — so run `make_rar_fixtures.sh` on a machine
that has WinRAR/rar, commit the four archives here, and uncomment the RAR rows in
`PasswordTests.swift`.
